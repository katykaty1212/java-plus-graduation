# ExploreWithMe — микросервисная архитектура

Дипломный проект. Сервис-афиша: пользователи публикуют события, другие ищут их и подают заявки, администраторы управляют категориями и подборками.

## Архитектура

Проект состоит из инфраструктуры и трёх микросервисов. Клиенты обращаются через единый Gateway.

| Сервис | Ответственность |
|---|---|
| Gateway | Единая точка входа, маршрутизация |
| User Service | Пользователи |
| Request Service | Заявки на участие |
| Event Service | События, категории, подборки |
| Eureka Server | Service Discovery |
| Config Server | Конфигурация сервисов |
| Stats Server | Статистика |

Все микросервисы используют одну общую базу данных.

Клиент → Gateway → { User Service, Request Service, Event Service }

Между собой сервисы общаются через OpenFeign: например, `event-service` дёргает `request-service` для подсчёта заявок, а `request-service` дёргает `event-service` для проверки события. Конфигурация всех сервисов хранится централизованно в Config Server.
